# uae-abu-dhabi-law

The law of the Emirate of Abu Dhabi as git history, starting with the judgments of the courts of Abu Dhabi Global
Market (ADGM Courts). Each judgment is one commit dated by the day it was given. See [STRUCTURE.md](STRUCTURE.md) for
the folders and [LICENSE](LICENSE) for the sources and their terms.

More: [global-law](https://github.com/lexifina/global-law), the law of many jurisdictions as one history.
